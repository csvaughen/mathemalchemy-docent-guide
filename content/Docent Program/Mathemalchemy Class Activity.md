# Activity: Mathemalchemy Class Activity

A single two-sided worksheet for a college class visiting [Mathemalchemy](https://mathemalchemy.org/). Ten questions in three parts: **codes** (ASCII, prime numbers, the Cryptography Quilt), **infinite series** (the Ball Arches, Zeno's Path, and a perpetuity, which is the same mathematics with dollars in it), and **polyhedra** (the Platonic solids and Euler's formula).

## How it runs

Bring the class to the exhibit for the end of a session and hand out the sheet. Most questions are answered by finding something and looking at it, so students start in the gallery and can finish there or at home. Each question leaves a few lines to write on.

The sheet asks what ASCII is, but not what the skateboarder's flag says. Students who want to crack it can move on to [[Decode the Banner]].

## Materials

- **[[Mathemalchemy Class Activity.pdf|The worksheet (PDF)]]**: letter size, printed double-sided. One per student.
- Pencils, and something to write on.

An answer key for instructors is available from the docent coordinator.
